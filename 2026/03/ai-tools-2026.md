## 文本与写作 AI

### 1. ChatGPT / Claude / Gemini

**适用场景**：通用问答、内容创作、代码辅助、学习研究

**核心优势**：
- 多轮对话能力，可以进行深入探讨
- 支持长文本处理（Claude 支持 200K tokens）
- 可以分析文档、图片等多种格式

**使用技巧**：
```
高效提示公式：
角色 + 任务 + 约束条件 + 输出格式

示例：
"你是一位资深产品经理（角色），
请为一款笔记应用写一份产品需求文档（任务），
目标用户是大学生，文档不超过 3 页（约束），
使用 Markdown 格式输出（格式）"
```

### 2. Notion AI

**适用场景**：笔记整理、文档撰写、会议记录总结

如果你已经在使用 Notion，Notion AI 可以：
- 一键总结长文档要点
- 将杂乱笔记整理成结构化内容
- 基于现有内容继续写作

### 3. Jasper / Copy.ai

**适用场景**：营销文案、广告创意、社交媒体内容

专门为营销场景优化的 AI 写作工具，提供：
- 50+ 营销文案模板
- 品牌声音定制
- SEO 优化建议

## 图像生成 AI

### 1. Midjourney

**适用场景**：艺术创作、概念设计、视觉灵感

**2026年新特性**：
- 支持更高分辨率输出（最高 4096×4096）
- 更好的文字渲染能力
- 风格一致性控制

**入门提示词公式**：
```
[主体描述] + [风格/艺术流派] + [光照/氛围] + [技术参数]

示例：
"a futuristic cityscape at sunset, 
cyberpunk style with neon lights, 
cinematic lighting, 
--ar 16:9 --v 6 --s 750"
```

### 2. Stable Diffusion XL

**适用场景**：本地部署、隐私要求高的场景、定制模型训练

开源优势：
- 完全免费，可本地运行
- 社区生态丰富（LoRA、ControlNet 等）
- 可以训练专属风格的模型

### 3. Adobe Firefly

**适用场景**：商业设计、与 Adobe 工作流集成

**特色功能**：
- 生成式填充（Generative Fill）
- 文字效果生成
- 矢量图形生成

## 代码与开发 AI

### 1. GitHub Copilot

**适用场景**：日常编码、学习新语言、快速原型

**最新能力**：
- 根据注释生成完整函数
- 解释复杂代码逻辑
- 提供重构建议

**使用建议**：
- 对于 boilerplate 代码非常高效
- 复杂算法仍需人工审查
- 结合单元测试确保正确性

### 2. Cursor

**适用场景**：AI 原生代码编辑器

基于 VS Code 的 AI 增强编辑器，特色功能：
- Ctrl+K：快速编辑代码
- Ctrl+L：与 AI 对话讨论代码
- 可以索引整个代码库进行问答

### 3. V0.dev

**适用场景**：快速生成 UI 组件

Vercel 推出的 AI 工具：
- 用自然语言描述生成 React 组件
- 基于 Tailwind CSS 和 shadcn/ui
- 可以直接复制代码使用

## 如何构建你的 AI 工具栈

### 初学者路线

**第 1 周**：掌握 ChatGPT/Claude 的基本使用
- 学习提示词工程基础
- 用于日常问答和写作辅助

**第 2-3 周**：尝试一个图像生成工具
- Midjourney 或 DALL-E 3
- 用于制作演示文稿配图、社交媒体内容

**第 4 周**：探索专业领域的 AI 工具
- 开发者：GitHub Copilot
- 设计师：Canva AI / Adobe Firefly
- 营销人员：Jasper / Copy.ai

### 进阶路线

1. **建立 AI 工作流** - 将多个 AI 工具串联使用
2. **学习 API 集成** - 用代码调用 AI 服务
3. **关注开源模型** - 本地部署降低成本
4. **参与社区** - 获取最新技巧和工具资讯

## 使用 AI 工具的注意事项

### ⚠️ 版权与合规

- 商用前确认工具的版权政策
- 某些生成内容可能需要标注 AI 生成
- 注意数据隐私，敏感信息谨慎上传

### ⚠️ 质量控制

- AI 输出始终需要人工审核
- 关键决策不能仅依赖 AI 建议
- 保持批判性思维，验证信息准确性

### ⚠️ 过度依赖

- AI 是助手而非替代品
- 保持核心技能的练习和提升
- 避免"AI 依赖症"，保持独立思考能力
